🎓 NET Lab – UGC NET Preparation & Exam Simulator

A browser-based study and practice platform designed for UGC NET Paper 1 and Paper 2, featuring interactive syllabus tracking, topic-wise learning, practice questions, mock tests, and a timed examination simulator.

NET Lab provides a simple, distraction-free learning environment to help aspirants prepare for the UGC NET examination in one place.

HTML5 – Application structure.
CSS3 – Styling, responsive layouts and themes.

🚀 How to Run Locally

Since NET Lab is a standalone HTML application, getting started is simple.

Clone this repository:
bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git

Open the downloaded project folder.
Open the HTML file in your web browser.

That's it! No additional installation is required.

🌍 Deploy Using GitHub Pages

You can host NET Lab for free using GitHub Pages.

Open your GitHub repository.
Navigate to Settings.
Select Pages.
Under Build and deployment, select Deploy from a branch.
Select the main branch and / (root) folder.
Click Save.
Wait for GitHub Pages to publish your website.

Your application will be available at:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/
